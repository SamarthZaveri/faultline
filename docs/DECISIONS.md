- 2026-11-07 | Each Kaggle notebook is a training point: per-notebook labels (validation method, every issue with type + line + note, A1-A5 included) judged against its competition's label as the answer key; written by Claude from compact extracts (relevant lines, detector numbering, no detector findings shown) under corpus/labels/GUIDELINES.md; train, then dev, test last with `--final`; evaluation stays grouped by competition | user: "each individual file is a training point"; 445 notebooks give varied, line-level labels, and data-independent issues apply to all of them; labels blind to the rules let rules and models be measured on the same ground truth | labels produced by the rules (circular); growing to 200 competitions first
- 2026-11-07 | Competition labels (corpus/labels/competitions.yaml): split type (random / group / temporal) with its key, task, official metric, stratify, small, confidence, reason; taken from how each competition built its test set, never from notebooks; all splits labeled, test labels used only in `--final` runs | the first model's labels must be independent of the code it judges; written once, reviewable in minutes | inferring labels from top-voted notebooks (circular); labeling only train/dev (test would need labels later anyway, and writing them now can't tune anything)
- 2026-11-06 | Injected-row detection adds a cross-fitted Mahalanobis distance (robust scaling, Ledoit-Wolf) next to the isolation forest; a row is flagged when either score passes its 99th held-out-reference percentile, and the reference rate is measured with the same either-score rule; rule id `poisoning.outlier_rows` | unit test on breast-cancer data: rows pushed 6 SD out on 3 of 30 columns (100% beyond the reference max on two) got 2/28 flagged by the forest alone, because forests score beyond-range values no higher than the reference's own extremes and a few columns get diluted; the distance catches rows whose values don't fit together | lowering the forest threshold (more false alarms); per-column range checks (heavy-tailed columns make them noisy)
- 2026-11-06 | RL rewards v1: v0 plus `escalate` (+8 needed a human, −4 trivial) and wrong fixes split into judge-caught (−6) vs slipped past visible checks (−40) | user choice; v0 made attempting always beat abstaining, so an unsure policy would ship risky fixes | v0 as is; v0 + escalate only

- 2026-11-04 | New Phase 3b "data–pipeline fit": profile each dataset, derive what its pipeline must do (split, stratify/groups, metrics, encoding, drift setup), flag mismatches at the code line, store a per-dataset data contract, and auto-fix tier1 mismatches with deterministic, verified rewrites (PRs only) | every dataset needs different splits/metrics/drift checks; fixed rules can't tell whether a random split is wrong; user wants easy issues fixed in this phase | one global rule set; waiting for the Phase 6 LLM agents to fix anything

- 2026-11-04 | Data detectors report a per-column shift only when PSI >= 0.2 (effect size) AND KS / chi-squared p < 0.01 Bonferroni-corrected over columns | large samples make every test significant; small ones make PSI noisy; both together keep false alarms low | PSI alone; p-values alone
- 2026-11-04 | Joint drift uses a classifier two-sample test (HistGradientBoosting, 70/30 holdout, AUC >= 0.55 and significant), localized by permutation importance; reported only when its top columns aren't already flagged per column | catches correlation changes no single-column test sees, and names columns | MMD (no localization), per-pair tests (quadratic)
- 2026-11-04 | Label flips use confident learning (Northcutt et al. 2021) implemented in ~30 lines on HistGradientBoosting out-of-fold probabilities; the alarm compares the issue rate with a trusted reference, and without one only a >= 10% rate is reported (low severity) | every real dataset has label noise, so an absolute count isn't evidence of poisoning; no new dependency | cleanlab
- 2026-11-04 | Injected-row detection: cross-fitted isolation forests on the reference (each scores held-out reference rows; current rows go to a random fold's forest), threshold at the 98th percentile of held-out scores, two-proportion test vs that rate; requires a reference | clean current rows and held-out reference rows are exchangeable, so the false-alarm rate is known; in-sample scores would understate it | contamination="auto"; one forest scored in-sample
- 2026-11-04 | Data findings: `Location.file` = dataset path/name, `node_id` = `data:<path>` (same as the graph), `columns` = columns involved; no raw cell values in findings; finding ids include columns when present (code finding ids unchanged) | one contract for code and data findings; several columns of one dataset need distinct ids; PII rule | separate DataFinding type
